# Aether Client — Minecraft 1.21.11

Fabric client mod for Minecraft 1.21.11.

Features:
- Right Shift ClickGUI
- Storage Finder
- Spawner Finder
- Range, color, opacity, line width and render-mode settings
- JSON configuration in config/aetherclient.json

This project uses the Minecraft 1.21.11 client source set and the 1.21.11 GizmoDrawing rendering API.
